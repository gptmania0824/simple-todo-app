# Simple Todo App

ブラウザだけで動作するシンプルなToDoアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 入力欄にタスクを入力して「追加」を押します。
3. タスクをクリックするかチェックボックスを操作すると完了状態を切り替えられます。
4. 「削除」を押すとタスクを削除できます。
5. タスクはブラウザの `localStorage` に保存されるため、ページを再読み込みしても残ります。

## 技術構成

- HTML
- CSS
- JavaScript
- localStorage

外部ライブラリやビルドツールは使用していません。

## 起動方法

リポジトリ内の `index.html` をブラウザで開くだけで利用できます。
